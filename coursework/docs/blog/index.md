## Сентябрь 2026 — Сделала сайт на MkDocs

Сайт — курсовая работа по дисциплине «Введение в веб-технологии». Основные шаги:

1. `pip install mkdocs mkdocs-material`
2. `mkdocs new .`
3. Настроила `mkdocs.yml` и написала страницы в Markdown
4. `mkdocs serve` — проверка, `mkdocs build` — сборка

Шпаргалка по Markdown:

| Что нужно        | Как написать                 |
|------------------|------------------------------|
| Заголовок        | `# Заголовок`                |
| **Жирный**       | `**текст**`                  |
| *Курсив*         | `*текст*`                    |
| Ссылка           | `[текст](адрес)`             |
| Картинка         | `![подпись](images/pic.png)` |
| Цитата           | `> текст`                    |
