# devops-lab-arlanova

Учебный проект для изучения DevOps на практике. Репозиторий предназначен для лабораторных работ, заметок и примеров по Git, Linux, автоматизации, контейнерам и CI/CD.

## Автор и контакты

- GitHub: [petrunina19257-hub](https://github.com/petrunina19257-hub)
- Вопросы и предложения: [Issues проекта](https://github.com/petrunina19257-hub/devops-lab-arlanova/issues)

## План изучения DevOps

- [ ] **Git и GitHub:** коммиты, ветки, Pull Request, слияние и разрешение конфликтов. Практика: выполнить начальную настройку этого репозитория.
- [ ] **Linux и командная строка:** файловая система, права доступа, процессы, пакеты и SSH. Практика: настроить учебную виртуальную машину.
- [ ] **Сети:** TCP/IP, DNS, HTTP/HTTPS и порты. Практика: проверить доступность сервиса и разобраться в его сетевых запросах.
- [ ] **Bash и Python:** переменные, условия, циклы и обработка ошибок. Практика: написать скрипт резервного копирования.
- [ ] **Docker и Docker Compose:** образы, контейнеры, тома и сети. Практика: запустить приложение с базой данных.
- [ ] **CI/CD и GitHub Actions:** автоматические проверки, сборка и доставка. Практика: добавить workflow с проверками на Pull Request.
- [ ] **Infrastructure as Code:** основы Terraform и Ansible. Практика: описать учебную инфраструктуру и автоматизировать её настройку.
- [ ] **Kubernetes:** Pod, Deployment, Service, ConfigMap и Secret. Практика: развернуть приложение в локальном кластере.
- [ ] **Мониторинг и логи:** метрики, Prometheus, Grafana и оповещения. Практика: собрать метрики учебного сервиса.
- [ ] **Итоговый проект:** собрать приложение, настроить CI/CD, развёртывание и мониторинг; описать запуск и восстановление.
